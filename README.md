# 🧑‍💻 Tab Central

A modern and minimal new tab page, designed for the AI era. Tab Central contains 3 search modes designed to get you from question to answer as quickly as possible, including an advanced AI chat running on GPT-5.4.

## How to access
Copy the link for the live demo at the bottom of the README and set it as your browser's default new tab page using the relevant extension below:
- [Chrome Web Store](https://chromewebstore.google.com/detail/new-tab-redirect/icpgjfneehieebagbmdbhnlpiopdcmna)
- [Firefox Add-ons](https://addons.mozilla.org/en-GB/firefox/addon/new-tab-override)
- [Edge Add-ons](https://microsoftedge.microsoft.com/addons/detail/custom-new-tab-url/oeibmbobgpgnbnlbaffdgebpeepfbnhi)

### OR
- Download the project files as a `.ZIP` or clone the repo using `git clone https://github.com/matthew-seaber/tab-central.git` in your terminal
- Run `bun install` to install the required dependencies
- Run `bun dev` to start a local development server (default: `http://localhost:3000`)

## Key features
- Seamlessly switch between a normal Google search, a non-AI search, and an AI chat using keybinds
- Add quick links and change the theme to customise the new tab page to your liking
- Intuitively designed page: typing when not focused on an input will automatically focus your cursor to the most relevant one at any given time

*Note: UI/UX has not been designed for vertical screens.*
